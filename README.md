# Безделица

Сайт и приложение в Телеграме (Telegram Mini App) для бренда украшений из серебра «Безделица».
Это один и тот же сайт: в браузере он открывается как обычный сайт, а в Телеграме — по кнопке у бота.

## Что внутри

| Файл | Что в нём |
| --- | --- |
| `index.html` | Страница: шапка, первый экран, каталог, блок «Почему мы», подвал |
| `styles.css` | Оформление: цвета, шрифты, светлая и тёмная тема |
| `catalog.js` | **Товары, цены и настройки.** Обычно правится только этот файл |
| `app.js` | Логика: фильтр, карточка товара, корзина, оформление заказа, связь с Телеграмом |

Сборка и установка не нужны: это обычные файлы, которые можно положить на любой хостинг.

## Как поменять товары

Откройте `catalog.js`. Каждый товар — блок вида:

```js
{
  id: "midnight-ring",        // латиница, без пробелов, не повторяется
  type: "ring",               // ring | earrings | necklace | bracelet
  name: "Кольцо «Полночь»",
  collection: "Полночь",
  price: 18900,
  stones: "Синий фианит…",
  weight: "6,2 г",
  sizes: ["16", "16,5", "17"], // только если есть размеры
  note: "Описание для карточки товара",
},
```

Когда товары станут настоящими, поставьте `demo: false`, чтобы убрать пометки «демо».
В `managerUsername` впишите юзернейм менеджера в Телеграме (без @). После оформления заказа появится кнопка «Написать менеджеру».

## Как посмотреть на компьютере

Откройте `index.html` двойным щелчком.

## Как опубликовать (бесплатно, через GitHub Pages)

1. В репозитории на GitHub: **Settings → Pages**.
2. В разделе *Build and deployment* выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через пару минут сайт будет доступен по адресу вида `https://<имя>.github.io/Bezdelitsa/`.
4. Свой домен (например, `bezdelica.ru`) подключается там же, в поле *Custom domain*. У регистратора домена нужно добавить DNS-записи, которые покажет GitHub.

## Как подключить к боту в Телеграме

1. Откройте **@BotFather** → `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App**.
2. Вставьте адрес сайта (обязательно `https://…`).
3. Там же можно настроить кнопку меню (**Menu Button**), чтобы приложение открывалось из чата с ботом.

Внутри Телеграма сайт сам подстраивается: берёт тему (светлую или тёмную), показывает нижнюю кнопку Телеграма («Корзина», «Оформить заказ») и кнопку «Назад».

## Безопасность

Токен бота — это пароль. Не храните его в этом репозитории и не пересылайте в чатах.
Сайту на этом этапе токен не нужен. Он понадобится, когда появится сервер, который будет сам пересылать заказы в Телеграм. Тогда токен кладут в настройки сервера (переменные окружения).
